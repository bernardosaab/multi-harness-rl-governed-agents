writegate-rl

Multi-harness RL for agents that write to a system of record. The model proposes; the harness decides. Every change passes through one fail-closed write gate, and every result below is read back from the ledger rather than taken from what the agent said.

model reply→inner harness parses (json / xml / pycall / plaintext)→ quote: exact diff + fingerprint + tier→sign (policy or human)→ execute only the signed payload→read the ledger back
